# 🔄 Telegram Mini App — Конвертер валют

Конвертер валют, который открывается прямо в Telegram. Курсы тянутся с бесплатного API
и кэшируются на час, поэтому приложение работает и без интернета — на последних сохранённых курсах.
Весь фронтенд — один HTML-файл без сборки и зависимостей, бот — 100 строк на Python.

```
│ Конвертер валют             │
│ Привет, Иван!               │
│ ┌─────────┐   ┌───────────┐ │

│ │ [USD ▾] │   │ [RUB ▾]   │ │
│ │ [ 100 ] │   │ [ 8123 ]  │ │
│ │ 100.00  │   │ 8,123.00  │ │  ← результат: 32px, Telegram-синий
│ │   USD   │   │    RUB    │ │
│ └─────────┘   └───────────┘ │
│  [ ⇅ Поменять местами ]     │
│  Курсы обновлены 29.08 14:30│
│  [☆ Избранное] [Поделиться] │
│                             │
│  ИЗБРАННЫЕ ПАРЫ             │
│  (USD → RUB) (EUR → USD)    │
│                             │
│  ИСТОРИЯ                    │
│  100 USD → 8 123 RUB · 14:30│
└─────────────────────────────┘
```

Тёмная тема по умолчанию (фон `#0a0e27`, акцент `#0088cc`), светлая — если светлая тема
в Telegram или в системе. На экранах уже 400 px колонки переносятся друг под друга,
при свапе валют карточки проигрывают короткую анимацию.

## Возможности

- ✅ **10 валют**: USD, EUR, RUB, GBP, JPY, CNY, KRW, INR, BRL, MXN
- ✅ **Актуальные курсы** через exchangerate-api, кэш в `localStorage` на 1 час
- ✅ **Работает офлайн** — показывает сохранённые курсы и метку «оффлайн»
- ✅ **История** последних конвертаций (хранится 100, показывается 5)
- ✅ **Избранные пары** до 5 штук, клик по паре подставляет её в конвертер
- ✅ **Поделиться результатом** в чат через Telegram Web Apps API
- ✅ **Конвертация в обе стороны**, свап валют, формат чисел `1,000,000.00`

## Технологии

| Слой | Что используется |
|------|------------------|
| Frontend | HTML + CSS (Flexbox, CSS-переменные) + ванильный JS — один файл, ноль зависимостей |
| Telegram | Telegram Web Apps API (`telegram-web-app.js`): тема, данные пользователя, `sendData` |
| Backend | Python 3.10+, [python-telegram-bot](https://docs.python-telegram-bot.org/) 22.x |
| Курсы | [exchangerate-api.com](https://api.exchangerate-api.com/v4/latest/USD) — free tier, без ключа |
| Хранилище | `localStorage` браузера: курсы, история, избранное |

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<user>/<repo>.git
cd <repo>
```

### 2. Установить зависимости Python

```bash
pip install -r requirements.txt
```

### 3. Получить токен бота

Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя и username →
получите токен вида `123456789:ABCdefGHI...`. Username бота тоже запомните.

### 4. Создать `.env`

```bash
cp .env.example .env
```

И вписать в него токен:

```
BOT_TOKEN=123456789:ABCdefGHIjklmnoPQRstUVwxyz
MINIAPP_URL=https://<user>.github.io/<repo>/index.html
```

### 5. ⚠️ Загрузить `index.html` на хостинг

**Это обязательный шаг.** Telegram не открывает Mini App с локального компьютера:
приложение грузится внутри клиента Telegram у пользователя, поэтому файл должен быть
доступен из интернета и **только по HTTPS** — `http://` и `localhost` клиент отклонит.

GitHub Pages (бесплатно):

```bash
git add . && git commit -m "converter" && git push
# Settings → Pages → Branch: main → /(root) → Save
# URL: https://<user>.github.io/<repo>/index.html
```

Vercel (бесплатно):

```bash
npx vercel --prod
```

### 6. Подставить свои адреса

- В `.env` → `MINIAPP_URL` = URL, который выдал хостинг.
- В `index.html`, в блоке `<script>`, замените имя бота — оно уходит в deep-link кнопки «Попробуй сам»:

```js
const BOT = 'my_converter_bot';
```

### 7. Запустить бота

```bash
python bot.py
```

Откройте бота в Telegram → `/start` → «💱 Открыть конвертер валют».

Подробное развёртывание (VPS, systemd) — в [DEPLOY.md](DEPLOY.md), локальное тестирование — в [TESTING.md](TESTING.md).

## Как использовать

1. `/start` в боте → нажать «💱 Открыть конвертер валют».
2. Выбрать валюту в колонке **Из** и ввести сумму — правая колонка пересчитывается на лету.
   Ввод в правую колонку работает так же, в обратную сторону.
3. **⇅ Поменять местами** — меняет валюты и суммы местами.
4. **☆ Избранное** — сохраняет текущую пару (до 5). Пары появляются чипами ниже,
   клик по чипу подставляет пару обратно в конвертер.
5. **Поделиться результатом** — отправляет конвертацию в чат.
6. Под кнопками — история: последние 5 конвертаций с датой и временем.
   Запись добавляется, когда вы закончили вводить сумму (не на каждый символ).

Строка под конвертером всегда показывает, когда обновлялись курсы,
и предупреждает, если используются старые (офлайн).

### Про кнопку «Поделиться»

- Приложение открыто **кнопкой клавиатуры** (`💱 Конвертер`) → срабатывает `tg.sendData()`:
  бот получает JSON и присылает в чат сообщение с курсом. Telegram при этом закрывает приложение — так устроен API.
- Приложение открыто **inline-кнопкой или из меню** → `sendData` недоступен, поэтому
  используется `switchInlineQuery` / ссылка `t.me/share/url` с готовым текстом.

Обе кнопки бот присылает по `/start`.

## Развёртывание на сервере

Фронтенд уже на статическом хостинге (шаг 5). Остаётся держать бота запущенным.

**Webhook вместо polling** — добавьте в `.env`:

```
WEBHOOK_URL=https://bot.example.com/
PORT=8080
```

Бот сам переключится в режим webhook при старте.

**Автозапуск через systemd** — `/etc/systemd/system/convbot.service`:

```ini
[Unit]
Description=Currency converter bot
After=network.target

[Service]
WorkingDirectory=/opt/conv
EnvironmentFile=/opt/conv/.env
ExecStart=/usr/bin/python3 bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now convbot
sudo journalctl -u convbot -f     # логи
```

## Как добавить новую валюту

Курсы приходят с API сразу для ~160 валют, поэтому нужен только пункт в списках.
В `index.html` добавьте одинаковый `<option>` в **оба** `<select>` (`#from-currency` и `#to-currency`):

```html
<option value="CHF">CHF — Швейцарский франк</option>
```

Код валюты — трёхбуквенный ISO 4217 и должен присутствовать в ответе API
(проверить: открыть https://api.exchangerate-api.com/v4/latest/USD и найти его в `rates`).
Никакого JS править не нужно.

## Как кастомизировать цвета

Все цвета — CSS-переменные в начале блока `<style>` в `index.html`:

```css
:root {
  --bg: #0a0e27;      /* фон страницы */
  --card: #1a1f3a;    /* фон карточек */
  --text: #ffffff;    /* основной текст */
  --muted: #999999;   /* лейблы, история */
  --accent: #0088cc;  /* Telegram-синий: кнопки, рамки, результат */
  --shadow: 0 2px 12px rgba(0, 0, 0, .35);
  --radius: 12px;     /* скругление карточек */
}
```

Светлая тема — те же переменные в блоке `@media (prefers-color-scheme: light)`,
а `body.dark-theme` / `body.light-theme` ниже позволяют теме Telegram перебить системную.
Меняйте значения только в этих трёх блоках — по всему остальному CSS цвета не захардкожены.

## Лимиты API

Free tier exchangerate-api: **~1500 запросов в месяц**, ключ не нужен, обновление курсов — раз в сутки.

Приложение кэширует курсы в `localStorage` на 1 час, то есть один пользователь тратит
максимум ~24 запроса в сутки, а обычно 1–2 за сессию. Запросы идут из браузера пользователя,
а не с вашего сервера. Если упрётесь в лимит — увеличьте `TTL` в `<script>`:

```js
const TTL = 6 * 60 * 60 * 1000;   // 6 часов вместо часа
```

Курсы всё равно обновляются раз в сутки, так что большой TTL почти ничего не стоит по точности.

## Возможные ошибки и решения

| Симптом | Причина и решение |
|---------|-------------------|
| `Ошибка: не задан BOT_TOKEN` | Нет `.env` или пустая переменная. `cp .env.example .env` и вписать токен |
| Кнопка не открывает приложение | `MINIAPP_URL` не HTTPS, недоступен снаружи или ведёт на несуществующий файл |
| Пустая белая страница в Telegram | Ошибка JS. Откройте URL в обычном браузере и посмотрите консоль |
| «Используются старые курсы (оффлайн)» | API недоступен, показан кэш — приложение продолжает работать, это норма |
| «Не удалось загрузить курсы» | Нет интернета **и** нет кэша (первый запуск офлайн). Откройте позже |
| «Поделиться» ничего не делает | Приложение открыто вне Telegram по прямой ссылке. Откройте через кнопку бота |
| Результат не появляется | В поле не число. Ввод, не похожий на число, игнорируется |
| История и избранное пропали | Очищен `localStorage`. Данные хранятся только на устройстве и никуда не отправляются |
| `Conflict: terminated by other getUpdates` | Бот запущен дважды. Остановите лишний процесс |

### Проверка логики

Откройте `index.html#test` в браузере — в консоли выполнятся assert'ы для `convertCurrency`
и форматирования чисел (`selftest done` = всё в порядке). Тест перезаписывает кэш курсов
тестовыми значениями, после проверки перезагрузите страницу без `#test`.
