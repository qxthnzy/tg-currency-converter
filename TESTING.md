# 🧪 Локальное тестирование Mini App

Приложение и бот — две разные части, и тестируются они по-разному:
`index.html` можно открыть в обычном браузере, а всё, что связано с Telegram
(приветствие по имени, тема, «Поделиться»), работает только внутри Telegram.

| Что проверяем | Способ |
|---------------|--------|
| Вёрстку, конвертацию, историю, избранное | способ 2 — браузер |
| Telegram-тему, имя пользователя, «Поделиться» | способ 1 — ngrok |

---

## Способ 1: через ngrok (полноценно, внутри Telegram)

Telegram открывает Mini App только по HTTPS-адресу, доступному из интернета.
ngrok выдаёт временный HTTPS-адрес для вашего локального сервера.

### 1. Установить ngrok

```bash
pip install pyngrok
```

При первом запуске понадобится бесплатный токен с [dashboard.ngrok.com](https://dashboard.ngrok.com/get-started/your-authtoken):

```bash
ngrok config add-authtoken <ваш-токен>
```

### 2. Терминал 1 — раздать файлы

```bash
python3 -m http.server 8000
```

> Раздавать нужно именно статику: `bot.py` работает через polling и никакого
> HTTP-сервера не поднимает — туннелировать его бессмысленно.

### 3. Терминал 2 — открыть туннель

```bash
ngrok http 8000
```

В выводе найдите строку:

```
Forwarding   https://abc123.ngrok-free.app -> http://localhost:8000
```

### 4. Скопировать HTTPS-адрес в `.env`

```
MINIAPP_URL=https://abc123.ngrok-free.app/index.html
```

> Адрес меняется при каждом перезапуске ngrok — правьте `.env` каждый раз.

### 5. Терминал 3 — запустить бота

```bash
python bot.py
```

В логе должно быть `запуск в режиме polling`. Если видите `MINIAPP_URL — заглушка`,
значит `.env` не подхватился.

### 6. Проверить в Telegram

1. Откройте своего бота → `/start`.
2. Нажмите **💱 Открыть конвертер валют** — приложение откроется поверх чата.
3. Для проверки «Поделиться результатом» открывайте приложение **кнопкой снизу**
   (`💱 Конвертер`) — только из неё Telegram разрешает отправку данных боту.

### Если что-то поменяли в коде

- Изменили `index.html` — просто обновите приложение в Telegram (потяните вниз или закройте/откройте).
- Изменили `bot.py` или `.env` — `Ctrl+C` и снова `python bot.py`.

## Способ 2: в браузере (быстро, без Telegram)

```bash
python3 -m http.server 8000
```

→ [http://localhost:8000](http://localhost:8000)

Работает: конвертация, свап, история, избранное, загрузка курсов, тёмная/светлая тема.
Не работает: приветствие по имени и отправка в чат — вместо неё результат копируется в буфер обмена.

> **Про двойной клик по файлу.** `index.html` откроется как `file:///Users/...`,
> но браузеры ограничивают такие страницы: запрос к API курсов и `localStorage`
> могут молча не сработать. Одна команда `python3 -m http.server` избавляет от этого класса проблем —
> используйте её вместо двойного клика.

### Быстрая проверка логики

Откройте [http://localhost:8000/index.html#test](http://localhost:8000/index.html#test) и загляните в консоль (F12):

```
selftest done
```

Значит `convertCurrency` и форматирование чисел работают. Красные `Assertion failed` — где-то поломка.
Тест перезаписывает кэш курсов тестовыми значениями — после проверки откройте страницу без `#test`.

## Тестовые сценарии

Проходите по порядку, каждый пункт — ожидаемый результат.

### 1. Базовая конвертация

1. В левой колонке валюта **USD**, введите `100`.
2. В правой выберите **EUR**.
   → Внизу правой карточки появится примерно `92.00 EUR` (точное число зависит от курса дня).
   → Под конвертером: «Курсы обновлены <дата>».

### 2. Обратный ввод

1. Введите `50` в **правую** колонку.
   → Пересчитается **левая**: сколько USD нужно для 50 EUR.

### 3. Поменять местами

1. Нажмите **⇅ Поменять местами**.
   → Валюты и суммы меняются местами, карточки коротко «дёргаются» (анимация).
   → Результат остаётся корректным: USD→EUR превращается в EUR→USD.

### 4. Избранное

1. Нажмите **☆ Избранное**.
   → Кнопка станет **★ В избранном** и пожелтеет.
   → В блоке «Избранные пары» появится чип `USD → EUR`.
2. Смените валюты на другую пару → кнопка снова станет `☆ Избранное`.
3. Кликните по чипу `USD → EUR`.
   → Пара подставится обратно в конвертер.
4. Сохраните 6 пар → останутся последние 5 (лимит).

### 5. История

1. Введите сумму и щёлкните мимо поля (или нажмите Tab) — запись добавляется по завершении ввода.
   → В блоке «История» появится строка `100.00 USD → 92.00 EUR · <дата, время>` с плавным появлением.
2. Сделайте 6 конвертаций → показываются последние 5.

### 6. Поделиться

1. Нажмите **Поделиться результатом**.
   - В Telegram, приложение открыто кнопкой снизу → приложение закроется, бот пришлёт в чат
     сообщение с курсом и кнопкой «Попробуй сам».
   - В Telegram, открыто inline-кнопкой → откроется выбор чата с готовым текстом.
   - В браузере → текст скопируется в буфер обмена.

### 7. Офлайн

1. Загрузите страницу с интернетом (курсы попадут в кэш).
2. F12 → **Network** → режим **Offline** → перезагрузите страницу.
   → Конвертация продолжает работать, под конвертером: «Используются старые курсы (оффлайн)».

### 8. Некорректный ввод

1. Введите `abc` или `-5`.
   → Ничего не пересчитывается, ошибок в консоли нет, старый результат остаётся на месте.

## Дебаг в DevTools (F12)

### Console

Ошибки JavaScript. Пусто = всё в порядке.
`selftest done` появляется только при открытии с `#test`.

### Network

Запрос к `api.exchangerate-api.com` должен пройти со статусом **200**.

- Запроса нет вообще → курсы взяты из кэша, он ещё свежий (обновляется раз в час).
- Красный/`failed` → нет интернета или API недоступен; приложение перейдёт на старые курсы.

Чтобы форсировать обновление, очистите хранилище (ниже) и перезагрузите страницу.

### Application → Local Storage

Все данные лежат в одном ключе — `conv`:

```json
{
  "rates": { "USD": 1, "EUR": 0.92, "RUB": 81.2 },
  "ratesUpdatedAt": 1756472400000,
  "favorites": [{ "from": "USD", "to": "EUR" }],
  "history": [{ "from": "USD", "to": "EUR", "amount": 100, "result": 92, "date": 1756472400000 }]
}
```

Сбросить всё (в консоли):

```js
localStorage.removeItem('conv'); location.reload();
```

Проверить, что кэш «протух» и курсы перезапросятся:

```js
const d = JSON.parse(localStorage.conv); d.ratesUpdatedAt = 0;
localStorage.conv = JSON.stringify(d); location.reload();
```

### Отладка внутри Telegram

DevTools в мобильном Telegram нет. Что делать:

- Проверяйте всё, что не требует Telegram, в браузере (способ 2) — там есть консоль.
- В **Telegram Desktop**: Настройки → Продвинутые → Экспериментальные настройки →
  включить **Enable webview inspecting**, затем правый клик по приложению → «Инспектировать».
- Быстрый способ увидеть ошибку на телефоне — временно показать её на экране:

```js
window.onerror = (m) => { document.getElementById('status').textContent = String(m); };
```

## Частые проблемы

| Симптом | Причина и решение |
|---------|-------------------|
| Кнопка в боте не открывает приложение | `MINIAPP_URL` не HTTPS, ngrok выключен или адрес устарел |
| Белый экран в Telegram | Ошибка JS — откройте тот же URL в браузере и посмотрите консоль |
| `ERR_NGROK_...` на странице | Туннель закрыт: перезапустите `ngrok http 8000` и обновите `.env` |
| Курсы не грузятся, в консоли CORS | Открыли файл двойным кликом (`file://`) — запустите `python3 -m http.server` |
| «Поделиться» ничего не делает | Приложение открыто не через бота, либо не кнопкой снизу — см. способ 1, шаг 6 |
| Результат не меняется | В поле не число: ввод игнорируется намеренно |
| Курсы не обновляются | Кэш живёт 1 час — сбросьте `localStorage` или подождите |
